# نظام شركة التراث للتوصيل السريع — النسخة الكاملة

خادم Node.js بدون مكتبات + واجهة عربية RTL. يتضمن:
- **لوحة التحكم** (`/`) للمدير والموظفين: الطلبات، الكشوفات، الصندوق، الأرباح، الاحصائيات، المستخدمون، الأسعار، المحافظات، الاعدادات.
- **بوابة العميل والمندوب** (`/app.html`) للجوال: العميل يضيف طلباته ويتابعها ويرى حسابه، والمندوب يرى طلباته ويغيّر حالتها.
- **أزرار اتصال وواتساب** مباشرة للزبون (في لوحة التحكم وفي بوابة العميل والمندوب).
- **دخول حقيقي**: كلمات المرور مشفّرة (scrypt) على الخادم، وجلسات موقّعة 30 يوما، وحدّ لمحاولات الدخول الخاطئة.
- **اشعارات تلجرام**: طلب جديد، تغيير حالة، تعيين مندوب، استيراد.
- كل البيانات على الخادم وتتزامن بين الاجهزة كل 5 ثوانٍ.

## واتساب وتتبع الطلب (جديد)
من اللوحة ← **واتساب وتتبع الطلب** (للمدير فقط):
1. اختر المزوّد: UltraMsg / Whapi.Cloud / Meta Cloud API / **مخصص** (اي مزوّد بالرابط والـHeaders وقالب Body، ويدعم `{{phone}}` و`{{message}}`)، والصق التوكن، ثم **رسالة تجريبية**.
2. فعّل الارسال التلقائي. تُرسل رسالة لهاتف الزبون عند: **تسليم الطلب للمندوب** (فيها اسم المندوب ورقمه وتفاصيل الطلب)، **في الطريق** (قيد التنفيذ)، **تم التسليم**، وايضا (اختياري) طلب جديد / مؤجل / راجع. كل قالب قابل للتعديل بمتغيرات مثل `{rep_name}` `{rep_phone}` `{order_no}` `{total}` `{track_link}`.
3. كل حدث يُرسل **مرة واحدة** لكل طلب، وسجل الارسال يظهر في نفس الصفحة. يعمل مع تغييرات اللوحة وبوابة المندوب.
4. **صفحة التتبع للزبائن**: `/track.html` (رابطها في شاشة الدخول وداخل الرسائل). الزبون يدخل رقم الطلب (+ آخر 4 ارقام من هاتفه للخصوصية، ويمكن تعطيلها). حدّد «رابط الموقع» في الاعدادات اذا كان الرابط في الرسائل غير صحيح.
ملاحظة Meta: الرسائل النصية تصل فقط ضمن 24 ساعة من آخر رد للزبون؛ للارسال المبادر يلزم قوالب معتمدة، ولذلك يفضّل UltraMsg/Whapi او «مخصص».

## وضع التشغيل: تجريبي أو سيرفر (يختاره المستخدم قبل الدخول)
في شاشة الدخول زران:
- **نسخة تجريبية**: بيانات تجريبية محفوظة في متصفحك فقط، بدون خادم. ادخل بالمستخدم `admin` وأي كلمة مرور (او `c1` عميل، `r1` مندوب). يعمل بفتح `public/index.html` مباشرة من الجهاز (دبل كليك). ميزات الخادم (تلجرام، تغيير كلمات المرور) تُعطّل فيه.
- **السيرفر**: الدخول الحقيقي بحسابك على الخادم، والبيانات مشتركة بين الأجهزة. يعمل فقط عند فتح الموقع عبر رابط الخادم.

البيانات التجريبية والحقيقية منفصلتان تماما، ويبقى الاختيار محفوظا في المتصفح. اذا فتحت الموقع عبر رابط الخادم يبدأ على «السيرفر» تلقائيا، واذا فتحت الملف من الجهاز يبدأ على «تجريبي».
في الوضع التجريبي تشترك لوحة التحكم وبوابة العميل/المندوب في نفس البيانات: طلب يضيفه العميل يظهر في اللوحة.

## الدخول (وضع السيرفر)
- المدير: المستخدم `admin` وكلمة المرور من متغير `ADMIN_PASS` (الافتراضي `admin123` — **غيّره فورا**).
- بقية المستخدمين التجريبيين (acc, entry, c1, r1 ...) كلمة مرورهم `123456`: غيّرها من «المستخدمين ← كلمة المرور» او احذفهم.
- المستخدم الجديد يُضاف من «المستخدمين»؛ اذا كان نوعه **عميل** او **مندوب** يدخل من نفس صفحة الدخول فيُحوَّل تلقائيا الى `/app.html`.

## الصلاحيات
| النوع | ما يصل اليه |
|---|---|
| مدير | كل شيء بما فيه المستخدمون والأسعار والاعدادات وتلجرام |
| محاسب / ادخال / مخزن / Call Center | لوحة التحكم (الطلبات والحسابات) بدون المستخدمين والأسعار والاعدادات وتلجرام |
| عميل | طلباته فقط: إضافة طلب، متابعة، حسابه |
| مندوب | الطلبات المسندة اليه فقط: تغيير الحالة، اتصال، واتساب، حسابه |

## ربط تلجرام
1. @BotFather ← `/newbot` ← انسخ التوكن.
2. أرسل رسالة للبوت.
3. اللوحة ← الإشعارات ← **ربط بوت تلجرام** ← الصق التوكن ← **اكتشاف Chat ID** ← **حفظ** ← **رسالة تجريبية**.
(او عيّن `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` في متغيرات البيئة.)

## تشغيل محلي
`ADMIN_PASS=كلمة_قوية node server.js` ثم http://localhost:3000

## النشر على Render
1. ارفع المجلد الى GitHub.
2. Render ← New ← Blueprint (يقرأ render.yaml) — يولّد `ADMIN_PASS` و`SECRET` تلقائيا؛ تجدهما في Environment.
3. الخطة المجانية تمسح `data.json` عند اعادة التشغيل. للحفظ الدائم: خطة مدفوعة + Disk على `/data` وعيّن `DB_FILE=/data/data.json`.
4. استخدم رابطا بـ HTTPS (Render يوفره).

## ملاحظات
- البيانات الحالية **تجريبية** (طلبات ومستخدمون): من الاعدادات ← «اعادة البيانات التجريبية» ثم احذف ما لا تحتاجه، او ابدأ بحذف المستخدمين التجريبيين.
- التخزين ملف JSON واحد: مناسب لعشرات المستخدمين؛ للحجم الكبير يلزم قاعدة بيانات.
- اذا عدّل مدير وموظف نفس الطلب في نفس الثواني الخمس، آخر حفظ يغلب.
